`trialrun.svg` is TrialRun's owned product mark. Its two brackets represent the base and pull-request applications; the lime slash is the recorded difference between them. It is not a third-party mark.

## Source decisions

- No distinct distributable Codex vector mark was found on OpenAI's current brand page or in the official `openai/codex` source repository. `openai.svg` is therefore the official OpenAI Blossom fallback, as requested.
- TrialRun did not previously have a reusable vector product mark. `trialrun.svg` was created for this repository from the existing `trial/run` slash motif and owned palette; it is deliberately simple enough to remain legible in the architecture diagram.

## SVG safety

The imported SVGs were screened before inclusion. None contains scripts, external `href`/`xlink:href` references, event-handler attributes, raster data URLs, or local-user path metadata, so no visual edits were required. Original `viewBox` values, aspect ratios, paths, and colors are preserved.
